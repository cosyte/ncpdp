The README now opens with the Cosyte logo, which follows your system light or dark theme on GitHub.

The image is the shared Cosyte lockup already used by the sibling parser packages, served from
`cosyte.com` in a light cut and a dark cut. Viewers that report a dark colour scheme get the dark
cut; everything else, including npmjs.com, gets the light one, which is the correct rendering there.

The `# @cosyte/ncpdp` heading and the summary line under it are unchanged, so nothing on the page is
duplicated: the artwork reads "Cosyte" and the heading names the package. No documentation text, no
API surface and no behaviour changed.
